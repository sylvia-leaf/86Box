86Box-SMP
=========

**This is not the official 86Box repository.**

This is a highly experimental fork of 86Box with work on multiprocessor (SMP)
machines. The 86Box project provides no support for it.

The official 86Box is at <https://86box.net> and <https://github.com/86Box/86Box>.
